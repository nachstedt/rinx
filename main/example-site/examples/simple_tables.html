Simple Tables

Simple tables trade the grid table's +---+ scaffolding for whitespace: runs of = on the top and bottom borders mark out the columns, and text lines up underneath them. They are less capable than grid tables — a cell cannot span rows — but far easier to type and to edit.

Because a simple table's border always has two or more = runs, it can never be confused with a section underline, which is a single unbroken run.

Table with a Header

An interior = rule separates the header rows from the body:

Fruit

Notes

Apple

Crisp, keeps well.

Pear

Best eaten the day it is picked.

The "Pear" row shows a cell continued onto a second line: a line whose first column is blank belongs to the row above it.
