Diagnostic codes

Every problem rinx finds carries a stable code. The build prints it in each warning:

warning: guide/intro.rst:42:18: link.broken-ref: broken ref 'missing'

and the language server shows it on each underline, linked to its section here. A .. noqa: comment naming codes silences them for the block that follows it:

.. noqa: link.broken-ref

See :ref:`missing`.

Codes are grouped by the construct they concern. Once a code is written in a .. noqa:, it is part of that document, so a code is never renamed lightly.

link

link.broken-ref

A :ref: whose label is in no document's index.

link.broken-hyperlink

A named hyperlink with no matching target.

link.broken-anonymous

An anonymous __ reference with no anonymous target left to consume.

link.broken-term

A :term: naming no glossary entry.

link.broken-option

An :option: naming no .. option:: definition.

link.broken-eq

An :eq: naming no labeled .. math::.

link.broken-object

A domain-object role (:func:, :py:class:, …) that resolved to nothing.

link.ambiguous-object

A dot-prefixed domain-object role whose suffix search matched several objects, so it was deliberately left unresolved.

link.broken-doc

A :doc: naming no document of this site, nor one any inventory it may search lists.

link.broken-any

An :any: role whose target is no label, document, term, option, equation or domain object, here or in any inventory it may search.

link.ambiguous-any

An :any: role whose target names several things at once, so it was deliberately left unresolved rather than linked to one of them.

link.type-mismatch

A domain-object role that resolved only via an object-type alias — the definition's own type differs from the one the role asked for.

link.unknown-inventory

An :external+name: role naming an inventory the build never declared.

link.broken-numref

A :numref: whose label is in no document's index, or labels something numfig never numbers — a paragraph, an uncaptioned code block. Sphinx calls both an "undefined label".

numref

numref.disabled

A :numref: to a figure, table or code block while numfig is off in rinx.toml, so nothing has a number to show.

numref.unnumbered

A :numref: to an element that exists but was given no number: it has no caption, no toctree reaches its document, or its section is not numbered.

numref.no-caption

A :numref: whose title shows {name} for an element with no caption.

numref.invalid-format

A :numref: title Sphinx could not apply: no %s, two of them, an unknown {field}, an unbalanced brace.

numref.external

An :external:numref: — an inventory holds no numbers.

pep

pep.invalid-number

A :pep: whose target is not a PEP number — Sphinx's "invalid PEP number". The role is shown as its source text.

pep-reference

pep-reference.invalid-number

A :pep-reference: whose target is not a number from 0 to 9999 — docutils' "PEP number must be a number from 0 to 9999". The role is shown as its source text.

rfc

rfc.invalid-number

An :rfc: whose target is not an RFC number — Sphinx's "invalid RFC number". The role is shown as its source text.

rfc-reference

rfc-reference.invalid-number

An :rfc-reference: whose target is not a number of at least 1 — docutils' "RFC number must be a number greater than or equal to 1". The role is shown as its source text.

cve

cve.invalid-id

A :cve: whose target is not a year and a sequence number, such as 2024-3094 — a check Sphinx does not make. The role is shown as its source text.

cwe

cwe.invalid-number

A :cwe: whose target is not a CWE number — Sphinx's "invalid CWE number". The role is shown as its source text.

index-role

index-role.invalid-single

An :index: whose entry is empty — :index:`!`, or an explicit single: with no value.

index-role.invalid-pair

An :index: whose pair: entry has no two ;-separated parts.

index-role.invalid-triple

An :index: whose triple: entry has no three ;-separated parts.

index-role.invalid-see

An :index: whose see: entry has no two ;-separated parts.

index-role.invalid-seealso

An :index: whose seealso: entry has no two ;-separated parts.

heading

heading.underline-too-short

A section adornment shorter than the title's display width, which docutils accepts and reports rather than rejecting.

heading.overline-mismatch

An overlined title whose underline differs from its overline in length or character — docutils' "Title overline & underline mismatch". The title is still a heading.

heading.missing-underline

An overline over a title with no underline below it — docutils' "Missing matching underline for section title overline", and its "Incomplete section title" at the end of a file. The lines stay text.

heading.adornment-without-title

Two adornment lines directly on top of each other, with no title between them — docutils' "Invalid section title or transition marker". The lines stay text.

heading.unexpected

A section title where none may stand: inside a block quote, list, table or directive body — docutils' "Unexpected section title". The title is still a heading, but sets no level for the document's own.

transition

transition.at-document-start

A transition (horizontal rule) as the document's first element, which docutils forbids.

transition.adjacent

A transition directly following another transition, with nothing between them.

transition.at-document-end

A transition as the document's last element, which docutils forbids.

table

table.grid.inconsistent-indent

A grid table line indented differently from the table's top border.

table.grid.width-mismatch

A grid table line whose width differs from the top border's, usually a misaligned + or | column boundary.

table.grid.unterminated

A grid table not closed by a border line.

table.grid.multiple-header-separators

A grid table with more than one = header/body separator line.

table.grid.no-rows

A grid table with no row content between its borders.

table.grid.no-body-rows

A grid table whose every row is a header row, leaving no body.

table.grid.no-columns

A grid table whose top border defines no columns.

table.grid.inconsistent-column-boundary

A grid table whose | column boundaries do not line up from row to row.

table.simple.under-indented

A simple table line indented less than the table's top border.

table.simple.border-width-mismatch

A simple table border whose width differs from the top border's.

table.simple.no-bottom-border

A simple table with no bottom border, or with no blank line after it.

table.simple.multiple-header-separators

A simple table with more than one header/body separator; only one is allowed.

table.simple.incomplete-column-span

A simple table column span (a - underline) that does not reach the table's right edge.

table.simple.text-in-margin

Simple table text written in the blank margin between two columns.

table.simple.unaligned-column-span

A simple table column span whose edges do not line up with the table's columns.

table.simple.empty-first-cell

A simple table line with an empty first cell, which docutils reads as a continuation and drops — start the row with an escaped space (a backslash, then a space) instead.

list

list.bullet-changed

Adjacent bullet lists with different bullet characters and no blank line between them.

list.enumerated-start-not-one

An enumerated list starting at an ordinal other than one. The list keeps its start value.

list.enumerated-not-recognised

Lines that look like an enumerated list but whose enumerators do not run consecutively, so the block is parsed as a paragraph instead.

list.enumerated-no-blank-line

An enumerated list ended by a less-indented line directly after it, with no blank line in between.

block-quote

block-quote.unindent-no-blank-line

A block quote ended because a less-indented line followed it directly, with no blank line in between.

line-block

line-block.ends-without-blank-line

A line block ended because a non-| line followed it directly, with no blank line in between.

directive

directive.unknown

A directive name this build does not recognize. Its body is never parsed, so everything inside it is lost to every later phase — which is why this is reported rather than left to the visible error block the renderer draws in its place.

directive.namespace-push-argument-missing

A .. c:namespace-push:: with no scope argument. Refused rather than accepted as a no-op push, which a later namespace-pop would then unbalance.

directive.toctree-unknown-option

A .. toctree:: option this build does not recognize. The option is ignored.

directive.contents-unknown-option

A .. contents:: option this build does not recognize. The option is ignored.

directive.sectnum-unknown-option

A .. sectnum:: option this build does not recognize. The option is ignored.

directive.dropdown-unknown-option

A .. dropdown:: option this build does not recognize. The option is ignored.

directive.grid-unknown-option

A .. grid:: option this build does not recognize. The option is ignored.

directive.grid-item-unknown-option

A .. grid-item:: option this build does not recognize. The option is ignored.

directive.button-link-unknown-option

A .. button-link:: option this build does not recognize. The option is ignored.

directive.entity-table-unknown-option

An .. entity-table:: / .. needtable:: option this build does not recognize. The option is ignored.

directive.entity-flow-unknown-option

An .. entity-flow:: / .. needflow:: option this build does not recognize. The option is ignored.

directive.entity-sequence-unknown-option

An .. entity-sequence:: / .. needsequence:: option this build does not recognize. The option is ignored.

directive.entity-pie-unknown-option

An .. entity-pie:: / .. needpie:: option this build does not recognize. The option is ignored.

directive.entity-bar-unknown-option

An .. entity-bar:: / .. needbar:: option this build does not recognize. The option is ignored.

directive.unknown-option

An option this build does not recognize on a directive with no option code of its own. The option is ignored.

directive.version-argument-missing

A .. versionadded::, .. versionchanged:: or .. deprecated:: with no version argument.

directive.title-argument-missing

A generic .. admonition:: with no title argument.

table

table.data.widths-count-mismatch

A list-table or csv-table whose :widths: gives a different number of values than the table has columns.

table.data.widths-invalid

A :widths: value that is not auto, grid, or a list of integers.

table.data.align-invalid

An :align: value other than left, center or right.

table.data.integer-invalid

A :header-rows: or :stub-columns: value that is not a non-negative integer.

table.data.row-cell-count

A list-table row with a different number of cells than the table's first row.

table.data.not-a-bullet-list

A list-table whose body is not a single bullet list of rows, each itself a bullet list of cells.

table.directive.no-content

The directive's content is empty (after its option lines).

table.directive.not-a-table

The directive's content parses, but isn't a table.

table.directive.multiple-blocks

The directive's content is more than just the one wrapped table.

csv

csv.url-unsupported

A csv-table with a :url: option. Fetching over the network would make the build non-hermetic; download the data and use :file: instead.

csv.file-and-content

A csv-table with both a :file: option and directive content.

csv.no-data

A csv-table with neither content nor a :file:, or whose data holds no rows.

csv.file-unreadable

A csv-table whose :file: could not be read — missing, outside the declared parse_data, or not readable.

csv.encoding-unsupported

A csv-table :encoding: other than UTF-8 (or its ASCII subset), which is all this build decodes.

csv.malformed-header

A csv-table :header: option whose CSV could not be parsed.

csv.malformed-data

A csv-table whose CSV data could not be parsed.

csv.header-rows-exceed

A csv-table asking for more :header-rows: than the table has rows.

csv.stub-columns-exceed

A csv-table asking for more :stub-columns: than the table has columns.

csv.dialect-invalid-char

A csv-table :delim:, :quote: or :escape: that is not a single character, space, tab, or a character code such as 0x20.

csv.dialect-non-ascii

A csv-table :delim:, :quote: or :escape: that is not an ASCII character.

doctest

doctest.option-not-supported

A doctest-family option that exists, but not on this directive — e.g. :options: on a .. testsetup::.

doctest.unknown-option

An option no doctest-family directive recognizes.

doctest.pyversion-invalid

A :pyversion: value that is not a comparison operator followed by a version, such as >= 3.10.

doctest.flag-missing-sign

A doctest flag in :options: not starting with + or -.

doctest.unknown-flag

A doctest flag in :options: that Python's doctest module does not define.

doctest.no-code

A doctest-family directive with an empty body, so there is nothing to run.

doctest.empty-group

An empty group name in a doctest-family directive's group argument. The block joins the default group.

math

math.empty-label

A :label:/:name: option with no value, so nothing could reference the equation and it stays unnumbered.

math.invalid-latex

LaTeX the math renderer rejected, reported while rendering rather than while parsing — the parser deliberately never inspects the LaTeX, since only the renderer knows the math backend.

code-block

code-block.empty-language

A language argument, or a .. highlight::, naming nothing at all.

code-block.empty-name

A :name: option with no value, so nothing could :ref: the block.

code-block.invalid-integer

A :lineno-start:, :dedent:, :number-lines: or :linenothreshold: whose value is not a positive integer.

code-block.emphasize-lines-invalid

An :emphasize-lines: that could not be read, or that names a line the block does not have.

code-block.unknown-language

A language with no grammar behind it, so the block was left unhighlighted. Reported while rendering rather than while parsing: only the renderer knows the set of languages the backend supports.

code-block.highlight-failed

A grammar that failed part-way through highlighting, so the block was left unhighlighted. Also render-time, and for the same reason.

role

role.invalid-argument

An argument that is not name(base), or a name no role could be written with, so the role was not defined.

role.unsupported-base

A base role other than code, or none at all — the only kind of role this build can derive — so the role was not defined.

role.builtin-name

A name this build already gives a role, which a custom role could never take over — the built-in one is matched first — so it was not defined.

role.empty-language

A :language: option with no value; the role is defined unhighlighted.

role.invalid-class

A :class: value that normalizes to no class name at all, so it was dropped.

default-role

default-role.unknown-role

An argument naming no role this build knows, so the default role was left as it was.

default-role.invalid-argument

An argument of more than one word, so the default role was left as it was.

default-role.unexpected-content

Options or a body, which the directive takes none of; the argument still applies.

interpreted

interpreted.multiple-roles

A role written both before and after the same text, as in :sub:`2`:sup:, which docutils allows only one of; shown as written.

interpreted.role-and-reference

A role and a hyperlink reference's _ on the same text, as in :ref:`x`_, which cannot both apply; shown as written.

code-role

code-role.unknown-language

A language with no grammar behind it, so the code was left unhighlighted. Reported while rendering, as for a code block.

code-role.highlight-failed

A grammar that failed part-way through highlighting, so the code was left unhighlighted.

image

image.missing-uri

The directive has no argument, so there is nothing to show.

image.invalid-length

A :height:, :width: or :figwidth: that is not a well-formed measurement, or that uses a unit CSS does not have.

image.invalid-scale

A :scale: that is not a non-negative integer percentage.

image.invalid-align

An :align: naming none of left/center/right — including the three vertical alignments, which docutils accepts only on an image inside a substitution definition.

image.invalid-loading

A :loading: naming none of embed/link/lazy.

image.empty-option-value

A :target: or :name: written with no value, so it could neither link anywhere nor be linked to.

image.content-not-allowed

Content below an .. image::, which takes none. A .. figure:: is the directive that has a body.

image.scale-no-dimensions

A :scale: with no :width: or :height: to apply it to. docutils would read the image file's own dimensions here; this build never opens the file while rendering, so the option is dropped rather than silently mis-sizing the image (see docs/decisions/007-image-assets.md).

image.embed-external

A :loading: embed on an external URL. Embedding one would mean fetching it during the build, which would stop the build being hermetic, so the image is linked instead.

image.embed-unavailable

A :loading: embed whose bytes never reached the renderer — in a Bazel build, an image missing from the library's images attribute. Reported while rendering, since only there is the asset sidecar known.

download

download.undeclared

A :download: naming a project file that never reached the site's _downloads/ directory — in a Bazel build, a file missing from the library's downloads attribute. Fails the build rather than warning, as an undeclared image does: the page would otherwise ship a link to nothing. Reported by the site's asset validation, the one step that sees both the documents and the bundle.

include

include.missing-path

The directive has no argument, so it names no file to splice in.

include.file-unreadable

The named file could not be read — in a Bazel build, usually one missing from the library's parse_data attribute.

include.cycle

A file that includes itself, directly or through a chain of other files. The chain is named in the message, since the offending edit may be in any link of it.

include.depth-exceeded

Includes nested more deeply than the parser will follow. Distinct from include.cycle: a very deep but finite chain is not a mistake in the same way, and the fix is different.

include.text-not-found

A :start-after:, :end-before:, :start-at: or :end-at: whose text appears nowhere in the file, so the selection could not be made.

include.invalid-line-range

A :start-line:/:end-line:/:lines: naming a range the file does not have, or one that ends before it begins.

include.empty-selection

Selection options that between them select nothing, so the directive would silently contribute an empty block.

include.encoding-unsupported

An :encoding: other than UTF-8 or a subset of it.

include.invalid-tab-width

A :tab-width: that is not an integer.

include.unknown-option

An option this directive does not have.

literalinclude

literalinclude.diff-unreadable

The :diff: file could not be read. Separate from include.file-unreadable so a document can suppress one without the other — they are different files and different mistakes.

literalinclude.lineno-match-unusable

A :lineno-match: on a selection that is not one contiguous run of lines, so there is no single number the first line could carry.

literalinclude.pyobject-unsupported

A :pyobject:, which would need a Python parser to find the named class or function. Refused rather than ignored, so the page never silently shows the whole file where one function was meant.

toctree

toctree.maxdepth-invalid

A :maxdepth: whose value is not a positive integer. Sphinx would treat the directive as having no depth limit at all, which silently renders a far larger tree than the author asked for.

toctree.numbered-invalid

A :numbered: whose value is present but is not a positive integer.

toctree.empty-name

A :name: option with no value, so nothing could :ref: the toctree.

toctree.missing-document

An entry naming a document the project does not contain. Detected while building the project index, since only there is the document list known.

toctree.glob-no-match

A :glob: pattern that matched no document.

toctree.duplicate-entry

A document reached by two different toctrees, so it appears twice in the navigation and only the first position orders it.

toctree.orphan-document

A document no toctree reaches, so a reader can only arrive at it by following a cross-reference. Suppress with a leading :orphan: field.

contents

contents.depth-invalid

A :depth: whose value is not a positive integer. Sphinx would treat the directive as having no depth limit at all, which silently lists a far deeper tree than the author asked for.

contents.backlinks-invalid

A :backlinks: value other than entry, top or none.

contents.empty-name

A :name: option with no value, so nothing could :ref: the table of contents.

dropdown

dropdown.invalid-color

A :color: naming none of the eleven semantic colours. The summary is left unpainted rather than given a class no stylesheet defines.

dropdown.unknown-icon

An :icon: naming no octicon. Reported here, while parsing, because this is where the :icon: line can be pointed at — the name itself is checked against the icon set the renderer draws from.

dropdown.invalid-chevron

A :chevron: other than right-down or down-up.

dropdown.invalid-animate

An :animate: other than fade-in or fade-in-slide-down.

dropdown.invalid-margin

A :margin: that is neither one nor four values, or that names a step off the 0–5 scale.

dropdown.empty-option-value

An option that needs a value but was written without one.

grid

grid.invalid-columns

A .. grid:: argument or a :columns: that is neither one nor four values, or that names something other than auto or a column from 1 to 12. The row or item is rendered without column classes rather than refused — see grid.rs for why a grid never dies of a bad option.

grid.invalid-gutter

A :gutter: that is neither one nor four values, or that names a step off the 0–5 scale. auto is a step a column count allows and a gutter does not, and lands here.

grid.invalid-spacing

A :margin: or :padding: that is neither one nor four values, or that names a step off the scale.

grid.invalid-child-align

A :child-align: other than start, end, center, justify or spaced.

grid.invalid-child-direction

A :child-direction: other than column or row.

grid.unexpected-child

Content written directly inside a .. grid:: that is not a .. grid-item::. Reported and kept, as sphinx-design keeps it: the layout is wrong, but dropping the content would be worse.

grid.item-outside-grid

A .. grid-item:: written outside any .. grid::. Likewise reported and still rendered.

grid.empty-option-value

An option that needs a value but was written without one.

button-link

button-link.invalid-color

A :color: naming none of the eleven semantic colours. The button is left unpainted rather than given a class no stylesheet defines.

button-link.invalid-align

An :align: other than left, right, center or justify.

button-link.missing-target

A .. button-link:: written with no URL to point at. The directive is drawn as an error block quoting its source, as an argument-less .. image:: is.

button-link.empty-option-value

An option that needs a value but was written without one.

button-link.unsupported-option

An option sphinx-design accepts here that this build refuses by name, rather than accepting and ignoring it.

button-link.unusable-outline

An :outline: with no :color: to outline. sphinx-design produces no class at all for that pair, so the option silently does nothing — reported for the reason uml.unusable-scale is.

button-link.nested-reference

A reference role written inside a button's label, which would nest one link inside another. The reference is rendered as its text alone.

sectnum

sectnum.depth-invalid

A :depth: whose value is not a positive integer. Treated as no depth limit, matching .. contents::'s own :depth:.

sectnum.start-invalid

A :start: whose value is not a positive integer (0 included — there is no sensible number to display at that value). The default of 1 is kept instead.

sectnum.empty-prefix

A :prefix: option with no value; docutils requires this option to carry one.

sectnum.empty-suffix

A :suffix: option with no value; docutils requires this option to carry one.

sectnum.unexpected-argument

An argument given to a directive docutils declares zero argument slots for. Real docutils reports this as a directive error rather than silently dropping it, so this build does too.

index

index.invalid-single

A single: entry with no value — Sphinx's "invalid single index entry". No entry is made.

index.invalid-pair

A pair: entry without two ;-separated parts — Sphinx's "invalid pair index entry". No entry is made.

index.invalid-triple

A triple: entry without three ;-separated parts. No entry is made.

index.invalid-see

A see: entry without two ;-separated parts. No entry is made.

index.invalid-seealso

A seealso: entry without two ;-separated parts. No entry is made.

c-decl

c-decl.unparsed

A c:function/c:type signature the C declaration parser could not read, so the name came from the fallback heuristic.

option

option.malformed-spec

An .. option:: spec that does not look like any recognised form.

substitution

substitution.undefined

A |name| reference matching no substitution definition, in this document or case-insensitively.

substitution.duplicate-definition

The same substitution name defined more than once. The first definition wins; the rest are reported and ignored.

substitution.circular-reference

A replace substitution whose content refers back to itself, directly or through a chain of other substitutions.

substitution.invalid-unicode-code

A unicode substitution's codepoint token was neither a decimal number, a recognized hexadecimal form, nor an XML character entity.

substitution.image-name-not-allowed

A :name: on an image inside a substitution definition. docutils refuses this: a substitution may be referenced more than once, but a name must be unique.

entity

entity.unknown-attribute

An option on an entity directive that its type declares as neither an attribute nor a relation.

entity.invalid-attribute-value

An attribute value that does not fit its declared type — a word where an int was declared, a value outside an enum's permitted set.

entity.missing-required-attribute

A required attribute the entity did not give a value for.

entity.malformed-argument

A directive argument a type takes none of, or one with more comma-separated parts than the type declares fields.

entity.invalid-id

An :id: that is not a legal entity id, or one that could not be derived because a source attribute had no value.

entity.id-pattern-mismatch

A legal id that does not match its type's declared id.pattern. Kept apart from entity.invalid-id because the entity keeps this id and links to it resolve: what is broken is a naming convention, which a migrating project may want to silence on its own.

entity.duplicate-id

Two entities in the project claiming one id. Found by the index phase, which is the first to see every document.

entity.unknown-target

A relation or role naming an entity that no document declares.

entity.disallowed-relation

A relation target whose type is outside the relation's declared to.

entity.missing-required-relation

A required relation the entity named no target for.

entity.multiple-relation-targets

Several targets on a relation declared to take exactly one.

entity.unknown-section

A sub-directive inside an entity that its type does not declare as a section.

entity.section-outside-entity

A section directive written outside any entity, which would otherwise render as nothing at all.

entity.duplicate-section

A section written more than once without being declared multiple.

entity.missing-required-section

A required section the entity did not write.

entity.role-type-mismatch

A role reference resolving to an entity whose type the role does not accept. Links anyway, as a domain-object type mismatch does.

entity.schema-mismatch

A document parsed against a different schema than the one the index is being built with — a build misconfiguration that would otherwise produce quietly wrong output.

entity-table

entity-table.invalid-filter

A :filter: this build's filter language cannot evaluate — either a syntax error, or a Python construct it deliberately does not support. The table still renders, listing everything, rather than vanishing.

entity-table.unknown-field

A :filter:, :columns: or :sort: naming a field no entity type declares and that is none of the built-in ones. Reported while parsing, where the schema is already in hand, rather than silently matching or showing nothing.

entity-table.duplicate-widths

Both :widths: and its sphinx-needs spelling :colwidths: given at once. Neither is guessed at, since the two disagreeing is exactly the case where picking one silently renders the wrong table.

entity-table.unsupported-style

A :style: this build has no rendering for — datatables, which is a JavaScript feature. A static table is rendered instead.

entity-table.empty-result

A table whose filter matched no entity at all. Reported for the reason .. literalinclude:: reports every way of selecting nothing: an empty table is far more often a mistaken filter than an intended statement.

entity-flow

entity-flow.invalid-filter

A :filter: this build's filter language cannot evaluate. The flowchart still draws, showing everything, for the reason entity-table.invalid-filter still lists everything.

entity-flow.unknown-field

A :filter: naming a field no entity type declares and that is none of the built-in ones. Reported while parsing, where the schema is in hand.

A template asking for an entity no document declares. Reported while rendering, because only then is the whole project's entity graph known.

uml.recursive-import

A uml() import that reaches itself, directly or through a cycle.

uml.empty-result

A diagram whose expansion drew nothing — most often a filter() that matched no entity.

Reported for the reason entity-table.empty-result is, and handled the same way: the page simply shows no picture. It has to be reported rather than compiled, because PlantUML refuses an empty diagram and would fail the whole build with a message about a generated file the author never wrote.

uml.diagrams-disabled

A diagram in a library that did not opt in with diagrams = True.

Diagram compilation is opt-in per library so that a project drawing nothing pays nothing for it — Bazel cannot know which documents hold a diagram before reading them, so the build must be told. This is what keeps the opt-in honest: a forgotten attribute fails on the directive's own line rather than shipping a page with a broken picture.

uml.save-unsupported

A :save:, which cannot be honoured: a sandboxed build action may only write files declared before it runs, and this path is written inside the document. The site's diagram_sources output group carries every diagram's expanded source instead.

uml.unknown-config

A :config: naming a PlantUML preamble the site config does not declare. Refused rather than ignored: a diagram silently missing the styling its author asked for looks finished and is wrong.

jinja

jinja.syntax

A document or template that is not valid Jinja. Reported rather than rendered: the parse then runs on the unrendered text, so the page is still built, but every {% %} in it stays visible as the tell.

jinja.undefined-value

A template reading a name bound by neither a {% set %} nor the library's jinja_context. Jinja2 would substitute the empty string; a page silently missing a value it asked for looks finished and is wrong.

jinja.render-error

A template that failed to render for a reason that is neither a syntax error nor an undefined value.

jinja.template-not-found

An {% include %} naming a template the build did not declare. Carries the loader's own explanation, which names the parse_data attribute the file belongs in.

jinja.whitespace-control

A whitespace-control modifier ({%-, -%}), which this build refuses: tracking which line a rendered line came from means injecting markers that a trim would swallow, and in reStructuredText a silently changed indent changes what a block contains.

jinja.dynamic-template-name

An {% include %} whose target is computed rather than written. Every file an action reads is declared before it runs, so a name that only exists mid-render could never be one of them.

jinja.recursive-include

An {% include %} chain that reaches a template already being rendered. Reported with the whole chain, because the offending edit may be in any link of it.

if-builder

if-builder.missing-builder

The directive has no argument, so it names no builder to compare against. Upstream gets docutils' generic "1 argument(s) required" here; a code of its own lets a document suppress this without suppressing every other malformed directive.

if-builder.unknown-builder

An argument that names no builder this build knows — including a multi-word one, since the directive takes the rest of its line. sphinx-simplepdf excludes the body silently, which makes a typo indistinguishable from a deliberate exclusion and deletes content with nothing to grep for.

if-builder.empty-body

A block whose builder matches but which has no content, so the directive contributes nothing where it was written to contribute something. A non-matching block is silent — emptiness only means a mistake on the branch that was selected.

noqa

noqa.unknown-code

A .. noqa: comment naming an id that is not a diagnostic code. Never suppressible: a suppression that silences the report of its own typo would be unfixable.
