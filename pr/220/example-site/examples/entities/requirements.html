Requirements

An entity with every kind of declaration

RequirementThe system shall boot within two secondsREQ_001

The unnamed leading prose is the content section. It is ordinary RST, so it may hold anything a document may hold.

Details
Statusin_progress
Tagsboot, safety-critical
Ownerplatform

Verification criteria

Measured with the boot harness on the reference board. A section's body is fully parsed, which is what lets it carry a nested directive:

Note

The two-second budget excludes firmware hand-off.

Safety comment

A boot timeout is treated as a hazard.

Safety comment

Declared multiple, so it may appear more than once.

Referring to entities from prose

A declared role carries a type check: The system shall boot within two seconds links to the requirement and shows its title. An explicit title overrides that, as in the boot budget.

The sphinx-needs spelling Boot sequence accepts any of the four types, and the built-in Boot timing regression test role accepts every type without being declared at all. Because every entity also registers an ordinary target, plain REQ_001 reaches one too.
