Audit events

The same mechanism expresses CPython's .. audit-event::, whose argument is a comma-separated signature rather than a title, and whose id is derived from its first field instead of generated.

Raises an auditing event os.system with arguments command. Added in version 3.8.

Raised when a shell command is about to run.

Raises an auditing event open with arguments path mode flags. Added in version 3.8.

Raised by every call that opens a file.

The reference os.system resolves against the derived id.
