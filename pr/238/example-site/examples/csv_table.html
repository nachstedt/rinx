CSV Tables

.. csv-table:: specifies a table as CSV data rather than character-art or a nested bullet list. It shares every presentation option with .. list-table:: — the two parse into the same node and render through the same code — and adds its own options for where the data comes from and how it is tokenized.

Cell content is parsed as full block-level RST, exactly like a grid table cell.
